## 📌 这是什么

一个面向**普通电脑使用者**的 AI 专家技能包（WorkBuddy 专家格式），只做两件事：

1. **扫清家底**：扫描临时文件与各应用缓存，量化空间占用，产出可视化分析报告（HTML，可打印/另存为 PDF，含「大白话 / 专业版」双版本切换）。
2. **确认后清理**：经用户明确确认后，清理临时文件、指定文件夹，或给出让用户自己动手的清理方法。

**核心铁律：宁可少清，不可多删。** 应用缓存识别保守——只清明确的 `Cache`/`Temp`/`Logs` 类可再生日录，绝不碰应用数据、配置、聊天记录，避免误删影响软件正常使用。

## ✨ 功能

| 能力 | 说明 |
|---|---|
| **空间分析** | 磁盘总览、临时文件、应用缓存、回收站/废纸篓、大文件定位；产出 `空间分析报告-YYYYMMDD.html`（占用环形图 + 分类占用条 + 三色状态灯 + 双版本 + 打印/PDF） |
| **经确认的清理** | 用户勾选后清理临时文件与白名单缓存；支持一键脚本（.bat/.sh）、系统自带入口（存储感知/存储管理）、手动命令三条路径 |
| **指定文件夹清理** | 先扫描分类、再让用户勾选子项，**不整目录无差别删除** |
| **清理方法教学** | 给用户可自行执行的命令与入口，附风险说明 |
| **应用缓存识别** | 内置 macOS/Windows 双平台 10 大类应用缓存白名单 + 通用识别方法论，拿不准一律不删 |

## 🚀 安装

将专家包目录放到专家目录下：

```bash
mkdir -p ~/.workbuddy/plugins/marketplaces/my-experts/plugins/
cp -R space-keeper ~/.workbuddy/plugins/marketplaces/my-experts/plugins/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

> 或直接通过 WorkBuddy 的「导入专家包」界面选择本仓库目录。

|---|---|
| 帮我看看电脑里临时文件和各应用缓存占了多少，出一份分析报告 | 只读扫描 → 生成 `空间分析报告-YYYYMMDD.html` |

## 🛡 安全设计

- **所有清理必须经用户确认**：默认只扫描、只报告、只建议，不擅自删除任何文件。
- **脚本删除路径硬编码白名单**：禁止通配符扫盘、禁止 `rm -rf /`、禁止删系统目录。
- **三级分级**：🟢 可放心清 / 🟡 谨慎清（先说明影响、先备份）/ 🔴 不要动。
- **不编造数据**：占用大小一律以实测扫描为准，无数据走自查清单，不凭感觉填数。
- **隐私**：不索取账号、密码、序列号与个人文件内容；扫描报告回传前提醒用户脱敏。

## 🧩 应用缓存识别（核心亮点）

- 🟢 **可放心清**：临时文件、浏览器缓存（Cache 子目录）、系统更新缓存、回收站/废纸篓、日志。
- 🟡 **谨慎清**：应用缓存（只清 Cache/Caches 子目录）、删后需重新下载/重新登录的缓存（微信图片、网盘缓存），先提醒备份。
- 🔴 **不要动**：应用数据（Application Support/AppData 整体）、Preferences、数据库、聊天记录、系统目录、用户文档。
- 内置**通用识别方法论**：目录名含 `Cache`/`Temp`/`Logs` 才可能安全；含 `Support`/`Data`/`Config`/`DB` 一律不碰；**拿不准 = 不删**。

## 📝 依赖与声明

- **无外部依赖**：纯提示词专家，不调用外部 API、不联网、不执行用户未确认的脚本。
- **运行时依赖**：生成脚本与报告需要文件写入能力；不支持时降级为「输出代码块 + 另存指引」。
- **系统自带工具为主力**：Windows 存储感知 / 磁盘清理 / 回收站；macOS 存储空间管理 / 优化存储 / 废纸篓。
- 不推荐付费「清理大师」类软件；不引导运行来源不明的清理脚本。
