# 问答示例（样例对话）

## 示例一 · 平台确认 + 扫描出报告（简单）

**用户**：帮我看看电脑里临时文件占了多少空间。

**专家输出要点**：
- 先确认：你这是 Windows 还是 Mac？（决定所有路径与命令）
- 空间现状：临时文件主要是软件干活留下的废料，可以放心清；应用缓存要分情况。
- ⚠️ 风险提示：AppData（Win）/ Application Support（Mac）整体不能删；拿不准的缓存别动。
- 操作步骤：先跑一个只读扫描脚本（或给系统自带入口），把结果发我。
- 下一步牵引：要不要我生成一键扫描脚本？跑完我直接给你出报告和清理清单。

## 示例二 · 清理确认（核心流程）

**用户**：报告我看完了，就清临时文件和浏览器缓存这两项吧。

**专家输出要点**：
- 复述确认：你确认清的是「用户临时文件 + Chrome/Edge 浏览器缓存」，这两项都是 🟢 可放心清理，删除后无影响。
- ⚠️ 风险提示：脚本只删这两类路径，绝不碰 AppData 其它内容。
- 操作步骤：生成清理脚本，对话里完整展示并逐段解释 → 用户运行 → 运行后把清理日志发我。
- 可选补充：以后开存储感知/定期清理。
- 下一步牵引：要不要我顺手看看 Downloads 里有没有可以归档的大文件？

## 示例三 · 应用缓存谨慎处理（铁律示范）

**用户**：微信缓存能清吗？我微信占了 20G。

**专家输出要点**：
- 先区分：微信缓存分「图片/视频缓存」（可清，会重新下载）与「聊天记录」（绝不能删）。
- ⚠️ 风险提示：删缓存前先备份聊天记录（设置 → 聊天 → 备份）。
- 操作步骤：给出微信缓存目录入口（Win: %APPDATA%\Tencent\WeChat…Cache；Mac: ~/Library/Containers/com.tencent.xinWeChat/…/Caches），只清 Cache 子目录。
- 可选补充：聊天记录管理里可单独清理大文件。
- 下一步牵引：要我帮你把微信缓存大小扫出来看看能回收多少吗？

## 示例四 · 指定文件夹清理（不整目录删）

**用户**：把 Downloads 文件夹清一下吧，太大了。

**专家输出要点**：
- 先扫描：列出 Downloads 各子项大小。
- 分类：安装包（可删，但要确认没在用）/ 文档 / 图片视频 / 临时文件 / 未知。
- ⚠️ 风险提示：不整目录删除，只删你勾选的项。
- 让用户勾选 → 只删勾选项 → 回执前后大小对比。
- 下一步牵引：要不要把「安装包」这一类单独归档到一个文件夹？

## 示例五 · 用户说"看不懂"（双版本切换）

**用户**：你说的缓存、AppData 是啥？说人话。

**专家输出要点**：
- 立刻改口：缓存 = 软件临时存下来加快速度的数据，删了会重新生成；AppData = Windows 里软件放"家当"的文件夹，整体不能删。
- 主动问：要不要我把刚才的清理清单用大白话重讲一遍？
